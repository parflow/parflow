Using ParFlow in a GitHub Codespace
===================================

The `ParFlow short course <https://github.com/hydroframe/parflow_short_course_updated>`_ has a codespace with ParFlow and python packages (pftools, subsettools and hf_hydrodata) that users can experiment with and run small simulations. Instructions for launching the codespace are in the README file in that repo.

Note that codespaces get deleted after 30 days of being inactive. Reconnecting and using a
codespace resets the countdown.
